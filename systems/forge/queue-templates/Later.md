# Later

> **What this is:** Work you know is coming but aren't ready to hand over. The queue never
> builds from here; when idle it researches each item and leaves one note under it.
> **Yours.** The item lines are yours; the indented `>` note under each is the queue's.
> **Hints:** One line per item. Edit the line, not the note — the note is rewritten in place
> on the next pass. Move an item to Inbox or Ready when you're ready; the note comes off.
